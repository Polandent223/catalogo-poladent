Comprobar autorización

Tu contraseña fue aceptada, pero el permiso de administrador necesita una corrección en Firebase.

UID de esta cuenta:

En Firebase abre Authentication → Usuarios y comprueba el UID. Después entra en Firestore → Datos y verifica el documento catalogAdmins / UID, con el campo active de tipo Boolean en true.

No debes cambiar las reglas para permitir a todos. Después de corregirlo, vuelve a iniciar sesión.

Acceso privado

Usa el correo y la contraseña del usuario que creaste en Firebase, no la contraseña de Google.

¿No recuerdas la contraseña? Abre Authentication → Usuarios, selecciona el menú ⋯ de tu usuario y elige Restablecer contraseña.

Cuentas y cotizaciones de clientes

Desactivado

Por ahora el cliente puede consultar el catálogo y solicitar productos sin crear una cuenta. Sus datos de contacto no generan un usuario automáticamente.

Reservado para cuando se implemente el portal seguro. La cédula podrá utilizarse como identificador, junto con una verificación de identidad; nunca como única contraseña. Todavía no puede activarse y no se guardan nuevas cuentas ni historiales.

En el futuro, tras desarrollar y probar el registro, el historial privado y las reglas de acceso, la administración podrá activar o desactivar esta opción sin modificar el catálogo.

Nuevo producto

Selecciona el área correcta para este producto. Puedes ordenar, renombrar, mostrar u ocultar las áreas desde Diseño del catálogo → Áreas de productos. La marca y la disponibilidad no cambian.

El precio USD se guarda primero en privado. Para mostrarlo en dólares y bolívares al cliente, utiliza Precios y tasa BCV. Si lo dejas vacío no se mostrará un monto.

Puedes subir fotos directamente mediante Cloudinary o pegar un enlace público. Los cambios se publican en el catálogo al guardar.
